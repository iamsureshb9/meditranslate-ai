# Project Rules

Project: MediTranslate AI

Tech Stack:
- Next.js 15
- TypeScript
- Tailwind
- shadcn/ui

Goals:
- Clean healthcare UI
- Simple architecture
- MVP-focused
- Hackathon-ready
- Production-looking frontend

Constraints:
- No authentication
- No database
- No overengineering
- Focus on demo quality

Coding Standards:
- Use reusable components
- Keep components modular
- Use TypeScript types
- Handle loading and error states
- Mobile responsive

Priority:
1. Working upload flow
2. AI output
3. Beautiful dashboard
4. Smooth demo experience
